# 공유 전술 상세 UI

## 변경 범위

- 로그인 상태에서는 공유 게시판과 동일한 `AppShell`과 공통 제목/메뉴를 사용한다.
- 비로그인 상태에서는 흰 배경의 클럽 헤더와 로그인 링크를 표시하되 공개 공유 링크 조회는 그대로 허용한다.
- 큰 둥근 패널/그라데이션 소개 영역을 제거한다. 제목 24px, 6px 컨트롤, 작성자/등록일, 읽기 전용 상태와 장면 목록을 사용한다.
- 두 종류의 코트, 장면 선택과 전체 애니메이션 재생은 유지한다. 재생 진행률 영역은 항상 자리를 확보해 재생 시 높이가 바뀌지 않는다.
- 상세에서 나가면 예약된 애니메이션 프레임을 취소한다. 공유 중지/잘못된/없는 공유는 표시하지 않는다.

## 검증

`node --test tests/*.test.cjs`, `npm run build`.

테스트 API와 로컬 브라우저로 관리자/회원/비로그인 조회, 게시판 복귀, 장면 선택, 재생/정지/완료, 읽기 전용 드래그 제한, 단일 장면 재생 비활성화, 공유 중지/잘못된 공유 차단을 확인한다. 코트가 비어 있지 않은지 화면 픽셀을 검사하고 320/390/768/1024/1440px와 긴 제목을 검증한다.

## 배포

서버 API/DB/환경변수 변경은 없다. 웹 버전만 반영한다. 운영 배포 전 실제 공유 링크로 비로그인·회원·관리자 조회를 확인한다. 문제 발생 시 이전 웹 버전으로 롤백하며 전술 원본/공유 스냅샷 데이터는 변경하지 않는다.
